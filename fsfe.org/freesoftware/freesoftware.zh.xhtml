8 什么是自由软件

什么是自由软件

自由软件的原则非常简单，但重要的是不要被其漫长历史所带来的深层复杂性所迷惑。了解四大自由及其含义、自由软件许可证的基本概念、自由软件带来的优势以及最常见的同义词。将视野拓展到软件领域之外，您还可以进一步了解自由软件与教育、采购和民主等其他领域的相互作用。

四大自由

自由软件指的是“自由”，而非价格。它向用户保障四项基本自由。只要缺少其中至少一项自由，该应用程序便属于专有软件，即非自由软件。

  • 使用

    自由软件可用于任何目的，且不受许可证过期或地域限制等约束。

  • 研究

    任何人都可以研究自由软件及其源代码，不受保密协议或类似条款的限制。

  • 共享

    自由软件几乎可以零成本地进行共享和复制。

  • 改进

    任何人都可以修改自由软件，并且这些改进可以公开发布和共享。

许可证

这四项自由由软件许可证赋予。软件许可证规定了程序可以被使用和重用的条件。要成为自由软件，许可证文本必须至少包含这四项自由。自由软件基金会和开放源代码促进会维护着经过审查和批准的许可证列表。如果某个应用程序的许可证未出现在这些列表之一中，通常不能被视为自由软件。

市面上有众多侧重点各异的许可证，一款软件产品或其部分组件也可以在不止一种许可证下获得授权。实际选择哪一种是一个战略性问题，但建议您选择最广泛使用的许可证之一。如需深入了解法律和许可问题，您可以阅读更多……

优势

自由软件关乎自由。在实践中，这为用户、组织、企业和政府带来了众多优势。

  • 自主权

    自由软件有助于开发和维护符合您自身需求的定制软件，而不仅仅迎合供应商的商业模式。

  • 协作

    自由软件可以由所有人以非排他性的方式共享和使用——服务于公共利益。

  • 共享与复制

    自由软件许可证允许运行无限数量的副本安装，而无需支付额外费用。

  • 无锁定

    自由软件许可证增强了对供应商的独立性，并在服务提供商方面提供了更多选择。

  • 重用代码

    自由软件赋予了将代码重用于其他项目的自由。

  • 创新

    自由软件许可证鼓励您的软件进行创新。

  • 竞争

    自由软件抵制垄断并促进竞争。

  • 安全性

    自由软件允许进行独立的安全检查，从而有助于更快地修补安全漏洞。

同义词

随着时间的推移，人们为自由软件提出了其他一些称谓。使用这些术语的动机通常是为了强调不同的侧重点并避免混淆。

自由软件及其上述四项自由最初由 GNU 项目于 1986 年定义。1998 年，“开源（Open Source）”作为自由软件的一项市场推广活动被提出，但其核心理念仍基于相同的自由。其他广为人知的自由软件称谓包括为避免英文单词“free”产生歧义而发起的“Libre Software”，以及作为“Free (Libre) Open Source Software”缩写的“FOSS”或“FLOSS”。

特定软件所提供的自由程度始终取决于其许可证，而非其标签。换言之，不要被指代相同特性的不同术语所迷惑。如果您对历史背景以及我们为何更倾向于使用最初的术语感兴趣，可以阅读更多……

还有一些术语常被误用作自由软件的同义词。“公有领域”便是其中之一，将自由软件与公有领域区分开来至关重要。简而言之，公有领域包含所有不适用版权的创意作品（包括软件）。这些作品的权利可能已经过期、已被明确放弃，或者可能不适用版权法。虽然这些是公有领域背后的普遍原则，但构成公有领域的决定性因素始终取决于作品使用所在国家或地区的法律原则。

虽然公有领域中的软件确实可能与自由软件的目标有所重叠，但通常情况下，自由软件并非公有领域的同义词。事实上，绝大多数自由软件都受版权规则的约束。尤其是在欧盟，现有的版权和专利制度使得准确界定作品是否属于公有领域变得十分困难。因此，为了避免在如何共享作品的意图上产生歧义，使用自由软件许可证比将作品置于公有领域更为可取，因为自由软件许可证能够就使用该软件所涉及的权利和义务提供清晰易懂的法律信息。

延伸探讨

自由软件的众多优势本身就是一种福祉，同时也为其他技术和非技术领域做出了积极贡献。自 2001 年欧洲自由软件基金会（FSFE）成立以来，我们一直在探索不同领域，以及自由软件如何在其中发挥积极作用。

  • 民主：技术深刻影响着当今社会。正因如此，对技术的控制权必须掌握在每个人手中，而不仅仅是少数群体。
  • 开放标准：开放标准允许人们自由且完全保真地共享各类数据。它们抵制锁定以及妨碍互操作性的其他人造壁垒，并促进供应商之间以及技术解决方案之间的自由选择。
  • 教育：自由软件在教学法上具有优越性；其自由与合作的基本精神正是民主环境中教育的应有精神。
  • 公共采购：自由软件非常适合公共部门。它是一种公共资源，政府机构可以相互使用、研究、改进和共享。对公民而言，这意味着透明度、成本效益，以及以最适合自己的方式与政府互动的自由。
  • 国际发展合作致力于全球经济、社会、生态和政治条件的可持续改善。自由软件正成为保障合法合规的国际合作与重用不可或缺的基础性技术——一项既能实现全球扩展又能兼顾本地适应性的技术。
  • 人工智能（AI）在过去几年中取得了巨大发展，且这一势头不会放缓——恰恰相反。虽然人工智能应用程序造福了许多公民的生活，但它们也可能削弱我们控制技术的能力，并使基本自由面临风险。我们致力于探索如何在自由软件许可证下发布人工智能应用程序，从而为更高的可访问性、透明度和公平性铺平道路。
  • 废除软件专利是一项重要举措，借此我们可以构建一个软件用户能够参与软件开发与分发的世界。软件专利赋予专利持有人禁止软件开发者使用专利创意的法律权力，从而为软件开发和分发增加了法律与财务风险。其结果是，软件专利最终会损害创新、经济与社会。
  • 可持续性：无论是过去、现在还是未来，每个人都可以不受限制地使用自由软件。正如我们的简短研究所表明的那样，借助自由软件，我们可以持续维护程序并防止软件过时。我们还可以维修和重新利用硬件，延长其使用寿命并节约自然资源。
